# 전전회 보고서 상세 작성 지침

## 적용 범위와 기준

이 문서는 전기전자회로 실험 보고서 작성과 수정 작업에서 적용한다. 사용자가 현재 작업에서 지정한 조건이 우선한다. 아래의 문체 규칙과 문장 예시를 구체적으로 적용한다.

서식은 이번 요청의 명시적 조건을 먼저 적용한다. 그다음 이 문서에 명시한 서식 규칙을 적용하고 나머지 배치는 현재 보고서에서 이어받는다. 현재 문서의 상속된 기본 서식이 여기의 명시적 조건과 다르면 명시적 조건을 적용한다. 사용자가 기존 서식을 그대로 유지하도록 지정하면 그 요청을 우선한다.

이 문서에는 문체 규칙 12개와 문체 예시 9개 및 Word 서식 규칙을 저장한다. 특정 실험의 제목과 수식 번호는 현재 보고서의 내용에 따라 정한다. 지침은 이 로컬 문서만으로 사용할 수 있으며 개인 문서의 외부 주소나 페이지 식별자를 포함하지 않는다.

## 보고서 문체 작성 지침

### 문장과 설명 방식

1. **개념은 쉬운 정의로 시작한다.**  
   처음 등장하는 개념은 무엇을 의미하는지 한두 문장으로 설명한다. 소자의 경우 어떤 입력으로 무엇을 제어하는지부터 설명한다.

2. **구체적인 상황을 떠올리게 한다.**  
   “~하는 상황을 생각해보자” 또는 “~인 경우를 고려해보자”처럼 설명할 조건을 제시한다. 어떤 값을 일정하게 두고 어떤 값을 변화시키는지 밝힌다.

3. **현상의 원인과 결과를 순서대로 설명한다.**  
   무엇이 변하고 그 변화가 다음 값에 어떤 영향을 주는지 연결한다. “~함에 따라”와 “~이므로” 및 “따라서”를 관계에 맞게 사용한다.

4. **기호는 문장으로 정의한다.**  
   “~을 X라 하자” 또는 “~을 X라 하면”의 형태로 물리량과 기호를 연결한다. 기호가 처음 등장하는 곳에서 의미를 설명한다.

5. **계산을 시작하는 이유를 밝힌다.**  
   “~을 구하기 위해” 또는 “여기서 우리가 구하려는 것은 ~이다”처럼 계산의 목적을 먼저 설명한다.

6. **수식 사이의 계산 과정을 말로 연결한다.**  
   어떤 식에 무엇을 대입하는지 밝힌다. “대입하여 정리하면”과 “두 식을 연립하면” 및 “~을 소거하면”처럼 실제 수행하는 연산을 구체적으로 표현한다.

7. **수식 다음에는 물리적 의미를 설명한다.**  
   수식에서 어떤 값이 증가하거나 감소하는지 설명한다. 그 관계가 소자의 동작에서 무엇을 의미하는지 이어서 설명한다.

8. **이미 설명한 내용을 다음 계산에 연결한다.**  
   앞서 정의한 기호와 수식 번호를 다시 사용한다. 어떤 측정값을 알고 있으면 어떤 미지수를 구할 수 있는지 밝힌다.

9. **가정과 적용 조건을 설명 과정에 포함한다.**  
   “~을 무시한다고 가정한다” 또는 “~인 경우에 적용한다”처럼 계산의 전제를 명시한다. 해당 가정이 결과 해석에 미치는 영향도 필요한 곳에서 설명한다.

10. **문장의 확신 정도를 근거에 맞춘다.**  
    정의와 성립하는 관계는 “~이다”와 “~한다”로 쓴다. 계산으로 얻은 결론은 “~임을 알 수 있다”로 쓴다. 추정이나 오차 원인은 “~로 보인다” 또는 “~일 것으로 예상된다”로 쓴다.

11. **독자에게 사고를 권하는 표현을 필요한 곳에 사용한다.**  
    “생각해보자”와 “고려해보자” 및 “관계를 얻어보자”를 상황 도입이나 계산 목적을 설명할 때 사용한다. 같은 표현을 연속해서 반복하지 않는다.

12. **한 문장에는 하나의 주요 설명을 담는다.**  
    원문의 설명 순서를 유지하면서 긴 문장은 나눈다. 쉼표 사용을 줄이고 문장 사이의 연결로 논리를 이어간다.

### 문체 예시

아래 문장은 작성 방식의 예시이다. 실제 보고서에서는 해당 실험의 조건과 근거에 맞게 내용을 바꾼다.

1. **개념을 정의하는 문장**  
   “모스펫은 게이트에 인가한 전압으로 드레인과 소스 사이의 전류를 제어하는 소자이다.”

2. **상황을 도입하는 문장**  
   “게이트 전압을 일정하게 두고 드레인 전압을 조금씩 높이는 상황을 생각해보자.”

3. **원인과 결과를 연결하는 문장**  
   “소스 저항에 흐르는 전류가 증가하면 소스 전압도 높아진다. 따라서 게이트 전압이 일정하여도 게이트–소스 전압은 감소한다.”

4. **기호를 정의하는 문장**  
   “게이트와 소스 사이에 걸리는 전압을 V_GS라 하고 드레인으로 흐르는 전류를 I_D라 하자.”

5. **계산의 목적을 제시하는 문장**  
   “여기서 우리가 구하려는 것은 문턱전압이다. 이를 구하기 위해 측정값으로 얻은 직선의 기울기와 절편을 살펴보자.”

6. **수식의 전개를 연결하는 문장**  
   “앞서 정의한 게이트–소스 전압을 포화 영역의 전류식에 대입하여 정리하면 다음과 같다.”

7. **수식의 의미를 해석하는 문장**  
   “이 수식은 게이트–소스 전압이 높아질수록 드레인 전류가 증가함을 보여준다.”

8. **다음 계산으로 연결하는 문장**  
   “직선의 기울기와 절편을 알고 있으면 앞서 정리한 관계식을 이용하여 문턱전압을 구할 수 있다.”

9. **가정과 결과 해석을 연결하는 문장**  
   “이 계산에서는 채널 길이 변조를 무시한다고 가정한다. 실제 측정값과 차이가 나타나면 이 가정의 영향을 살펴볼 필요가 있다.”

## Word 실험 보고서 작성 지침

전기전자회로 실험 보고서를 작성할 때 다음 규칙을 적용한다. 사용자가 새로 지정한 조건이 있으면 해당 조건을 우선한다.

1. **보고서 양식**
   기존 일반물리학실험1 pbl실험의 이론 구성과 설명 방식을 참고한다.

2. **쉼표 사용**
   쉼표 사용을 자제한다. 문장이 길어지면 의미에 따라 문장을 나눈다.

3. **문체**
   기존 일반물리학실험1 pbl실험 보고서의 문체를 따른다. 개념과 상황을 설명하고 기호를 정의한 뒤 수식을 제시한다. 문장 종결은 ‘~이다’와 ‘~한다’를 기본으로 한다.

4. **수식의 재사용**
   이론에서 제시한 수식을 이후 이론값 계산과 측정 결과 분석에 다시 사용할 수 있도록 구성한다. 필요한 변수의 정의와 적용 조건을 함께 설명한다.

5. **Word에 붙여 넣기**
   본문과 수식 및 수식 번호를 Word 보고서에 바로 옮겨 사용할 수 있도록 작성한다.

6. **글꼴과 크기**
   기본 글꼴은 HY신명조로 설정한다. 글씨 크기는 10pt로 맞춘다.

7. **현재 작성된 내용과의 일관성**
   사용자가 작성하거나 수정한 부분을 문체와 서식의 기준으로 삼는다. 새로운 내용은 현재 문서의 제목 번호에 이어 같은 형식으로 작성한다. 기존 절을 수정하거나 교체하면 해당 절의 제목 번호를 유지한다.

8. **소제목**
   이론 소제목은 ①·②·③과 같은 원문자 번호로 구분한다. 소제목은 굵게 표시한다.

9. **설명 순서**
   각 내용은 ‘개념과 상황 설명 → 기호 정의와 적용 조건 → 수식 → 수식의 의미와 활용 방법’ 순서로 작성한다.

10. **수식 번호**
    새로운 내용을 추가하거나 번호를 이어 쓰도록 요청받으면 현재 문서의 마지막 번호 다음부터 연속으로 부여한다. 기존 절을 수정하거나 교체하면 기존 수식 번호와 본문 참조를 유지한다. 식을 추가하거나 삭제하여 번호가 바뀌면 영향을 받는 참조도 함께 확인한다. 새 보고서는 지정된 번호가 없으면 [수식 1]부터 시작한다. 사용자가 시작 번호를 지정하면 해당 번호를 사용한다. 본문에서도 같은 번호를 참조한다.

11. **수식 배치**
    독립된 수식은 가운데에 배치한다. 수식 번호는 같은 줄의 오른쪽에 `[수식 n]` 형식으로 배치한다.

12. **수식과 기호의 형식**
    Word에서 편집할 수 있는 기본 수식 형식을 사용한다. 본문에 등장하는 변수에도 아래첨자와 위첨자를 정확히 적용한다.

13. **페이지와 본문 서식**
    A4 용지를 사용한다. 상하좌우 여백은 1.27cm로 설정한다. 본문은 양쪽 정렬한다. 첫 줄 들여쓰기는 적용하지 않는다.

14. **단락 간격**
    본문 단락 뒤 간격은 8pt로 설정한다. 독립된 수식 앞뒤에는 빈 문단을 하나씩 두어 본문과 구분한다.

15. **왼쪽 검은 네모 표시 제거**
    ‘현재 단락과 다음 단락을 항상 같은 페이지에 배치’와 ‘현재 단락을 나누지 않음’을 해제한다. 제목과 본문 및 수식 앞뒤의 빈 문단에도 동일하게 적용한다.

## 수식과 Word 서식 적용 방법

1. 본문은 HY신명조 10pt를 사용한다. 한글과 영문 글꼴 속성을 모두 확인한다. 제목을 굵게 표시할 때도 기본 글씨 크기를 유지한다.
2. 수식은 Word 기본 수식인 OMML 등 편집 가능한 형식으로 작성한다. 수식용 글꼴이 필요한 기호는 정상 표시되는지 확인하고 수식 글씨 크기는 10pt로 맞춘다. 본문 변수에도 아래첨자와 위첨자를 적용한다.
3. 독립 수식은 가운데에 놓고 같은 줄 오른쪽에 [수식 n]을 배치한다. 가운데 탭과 오른쪽 탭 등 문서 너비에 따라 정렬되는 방법을 사용한다.
4. 독립 수식 앞뒤에 빈 문단을 하나씩 두고 본문 단락 뒤 간격은 8pt로 설정한다. 첫 줄 들여쓰기는 0으로 설정한다. 기존 문서에서 문자 단위 들여쓰기를 상속하면 firstLineChars도 0으로 명시한다. 이론 소제목은 굵은 원문자 번호를 사용한다.
5. 제목과 본문 및 수식과 빈 문단에서 '다음 문단과 함께'와 '줄 나누지 않음'을 명시적으로 해제한다. 스타일에서 상속되는 설정도 확인한다. OOXML에서는 keepNext와 keepLines를 false로 설정하면 된다. 이 속성을 켜서 수식과 설명을 묶지 않는다.
6. 기존 문서에 이어 쓰거나 일부를 수정할 때는 해당 내용의 번호와 기호 및 서식 맥락을 확인한다. 사용자가 현재 작업에서 별도의 배치나 서식을 지정하면 그 조건을 적용한다.

## 이론과 결과를 연결하는 방법

1. 이론에서 사용할 기호의 정의와 단위를 밝힌다. 같은 물리량의 기호와 계수 정의를 일관되게 유지한다.
2. 기본식에서 실험 회로에 필요한 식을 얻을 때는 대입하거나 소거하는 대상을 설명한다. 구하려는 물리량에 대해 정리한다.
3. 이후 계산에서 어느 측정값을 어느 수식에 넣는지 설명한다. 단위를 변환하면 변환 관계를 확인한다.
4. 실험별 전원 조건과 소자값 및 파형과 근사는 실습 자료와 실제 기록에서 확인한다. 모스펫 예시 문장을 다른 실험의 사실로 사용하지 않는다.
5. 측정값이 없으면 기호식을 작성하고 필요한 입력값을 밝힌다. 측정 결과가 제공되기 전에는 관측했다고 서술하지 않는다.
6. 오차 원인을 설명할 때는 확인한 사실과 가능한 원인을 구분한다. 근거의 강도에 맞춰 '확인했다'와 '알 수 있다' 및 '보인다'를 선택한다.
